ReelParty auf iPads veroeffentlichen (ohne PC)

1. ZIP in der iPad-App Dateien entpacken.
2. https://github.com/new in Safari oeffnen und kostenloses Repository 'reelparty' erstellen.
3. Im neuen Repository 'Add file' > 'Upload files' waehlen und NUR die Datei server.js hochladen.
4. Unten 'Commit changes' anklicken. WICHTIG: server.js muss im Hauptverzeichnis liegen.
5. https://dashboard.render.com oeffnen. New > Web Service.
6. GitHub verbinden und Repository reelparty auswaehlen.
7. Language: Node. Build Command: echo ready. Start Command: node server.js. Plan: Free.
8. 'Create Web Service' waehlen und die ausgegebene HTTPS-Adresse auf allen iPads aufrufen.
9. Eine Person erstellt den Raum; sie teilt den Link mit bis zu drei weiteren Personen.

Die App synchronisiert Raum, Chat, Reel-Warteschlange und Reel-Wechsel live.
Instagram erlaubt keine sekundenexakte Playback-Steuerung der eingebetteten Reels.

Die Gratis-Instanz von Render kann nach 15 Minuten Inaktivitaet einschlafen und
beim naechsten Aufruf einige Zeit zum Starten benoetigen. Raumdaten gehen bei
Server-Neustarts verloren.
